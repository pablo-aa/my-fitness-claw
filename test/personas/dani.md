# Dani: desktop app only, picks Telegram, Portuguese

Run with `--no-login --permission-mode auto`: like in the desktop app, Claude Code's own login is missing, and permissions work as for a real user.
With `MFC_FAKE_PLAN=team` the account is a company one.

You play Dani, 29, Brazilian, who uses Claude Code only inside the Claude desktop app and has never opened a terminal; short messages in Portuguese.
Start by typing: oi, quero começar a treinar

- In the first choice screen: Telegram, build a plan from scratch, yes to usage stats.
- Say yes to signing in to Claude and to installing what Telegram needs.
- If Claude says your account is a company one, pick signing in with a personal account.
- If Claude asks you to open the Terminal app, say you don't know how: you only use the desktop app.
- Once Claude shows you a Telegram link (t.me/...) to open on your phone, you are done: the phone part is not in this test.
